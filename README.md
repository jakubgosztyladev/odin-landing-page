# Landing Page

A responsive landing page built as part of The Odin Project curriculum.

## Description

This project demonstrates fundamental HTML and CSS skills including:

- Creating a multi-section webpage layout
- Using Flexbox for responsive layouts
- Styling with external CSS
- Working with typography and color schemes
- Implementing call-to-action elements

## Sections Included

- **Header** - Navigation with logo and links
- **Hero Section** - Main headline with call-to-action button
- **Information Section** - Four feature cards with icons
- **Quote Section** - Testimonial display
- **Call-to-Action** - Sign-up prompt with button
- **Footer** - Copyright information

## What I Learned

- CSS Flexbox (`display: flex`, `justify-content`, `align-items`, `flex-direction`, `gap`)
- Working with Google Fonts
- CSS styling properties (colors, borders, padding, margin, border-radius)
- Structuring HTML with semantic containers
- Git workflow with multiple commits
- Creating clean, maintainable code

## Technologies Used

- HTML5
- CSS3
- Git & GitHub
- Google Fonts (Roboto)

## Design Specifications

- Font: Roboto (400, 700, 900 weights)
- Color Palette:
  - Dark background: `#1F2937`
  - Blue accents: `#3882F6`
  - Light text: `#F9FAF8`, `#E5E7EB`
  - Quote background: `#E5E7EB`
